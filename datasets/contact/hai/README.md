# H–AI conversations

Place the separate human and AI channels here, one directory per recording ID.
The paper inventory contains 213 scored recordings (70 dev, 143 test).
Use the exact IDs in `data/splits.csv`, rather than an unfiltered archive count.
`python -m contact.dataset init` creates the expected locations and manifest.
See [../../README.md](../../README.md) for the audio format and commands.
